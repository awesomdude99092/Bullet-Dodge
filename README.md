download the installer and run it. i would suggest pressing d for default directory when prompted unless you have a reason to put it elsewhere. default directory is 
"C:\Users\you\AppData\local\BulletDodge". input "y" or "n" for shortcut on desktop, then your done. if you want new versions 
(they will come out sporadically but often enough), then simply download the new version's installer and run, it will overide the old game,
and it won't reset your scores.
